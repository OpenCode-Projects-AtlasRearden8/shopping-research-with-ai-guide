# Appendix B · Glossary

Every term of jargon this manual uses, plus a few that spec sheets and sales pages will throw at you. Definitions are plain on purpose; precise-enough beats textbook.

| Term | Plain English |
| --- | --- |
| Affiliate link | A link that pays the sharer a commission whenever someone buys through it. Legal and common; just know that rankings and money now share an address. |
| AI model (LLM) | A language model: software trained on huge amounts of text that predicts useful continuations, summarizes, translates, and converses. Great at reading, brilliant at pretending to be sure. |
| Certified refurbished | A returned or used item made sale-worthy again. "Certified" means something only when the maker or an authorized repairer did the certifying. |
| Chip generation | Which vintage of processor, not its speed. Newer generations beat higher numbers on older ones, usually with less heat and better battery life. |
| Delivered (or "fob") vs installed | For appliances: does the price include carrying it in and hooking it up, or just leaving a box? Ask before the truck arrives. |
| eMMC | Slow built-in storage, the budget cousin of SSD. Fine for a simple tablet; a lifetime slowdown in a laptop. |
| eSIM | A SIM card as software instead of a plastic chip. Convenient for switching plans; requires carrier support. |
| ENERGY STAR | A certification for efficient appliances and electronics. Treat it as a floor; compare actual yearly energy use beside it. |
| Firmware | The software inside the appliance itself. Matters because a smart fridge is only as smart as its last update. |
| Firmness scale | A 1-to-10 softness score, and it is brand-specific. One maker's 7 is another's 5; the trial period outranks the number. |
| Hallucination | When an AI model confidently states something untrue. Tamed by quoting, counting, and fact-checking, which is what [Chapter 2](ai-reviews.html) teaches. |
| Inverter compressor | A motor that runs at variable speeds instead of strictly on/off. Quieter, steadier, and cheaper to run; common in good fridges and HVAC. |
| IP rating | Dust and water protection, in two digits: first is solids (6 is tight), second is liquids (7 dunked briefly, 8 deeper or longer). |
| Memory foam | The contouring foam that slowly hugs you back. Excellent pressure relief; notorious for sleeping warm. |
| mAh / Wh | Battery capacity units: mAh for phones, Wh for laptops and bigger things. Wh is the honest cross-device one (volts differ). |
| MSRP | Manufacturer's suggested retail price: an anchor, not an oracle. Many products never actually sell at MSRP. |
| Nit | A unit of screen brightness. 250 nits is fine indoors; 400 or more handles a sunny window. |
| OLED | Screen tech where every pixel lights itself: true blacks and rich contrast, with a small long-term burn-in risk if you leave static images parked. |
| Off-gassing | The new-foam smell from packaging chemistry. Usually fades within days; look for certifications like CertiPUR-US if it worries you. |
| Open box | An item someone bought, opened, and returned. Often near-new at a discount; inspect quickly while the return window is free. |
| Pocketed coil | Springs, each in its own fabric sleeve, so they move separately. The reason hybrid mattresses transfer less partner-tossing. |
| Pre-mortem | A planning trick: imagine the plan failed, then work backwards to likely causes. Free in [Chapter 6](ask-missing.html), and the best five minutes in shopping. |
| Price anchor | A displayed "was price" chosen to make the sale price look generous. Check a price-history site before believing it. |
| Price anchor theater | Same trick, louder. See [Chapter 5](timing.html). |
| Soldered RAM | Memory soldered to the board, permanently. Buy the size you'll need for the life of the machine, because there's no lane to upgrade. |
| Spec sheet | The maker's menu of exact numbers for a product. The most trustworthy document in shopping; [Chapter 4](spec-sheets.html) translates it. |
| Thunderbolt | A high-speed standard that lives inside the USB-C plug shape. Every Thunderbolt port is USB-C; not every USB-C port is Thunderbolt. |
| Update policy | How many years the maker promises OS updates and security patches. Long support quietly extends the life (and value) of a gadget. |
| Verified purchase | A review left by someone who bought the item on that site. Proof of purchase, not of honesty; bought reviews are often "verified" too. |
| White-glove delivery | Delivery where strangers bring it in, assemble it, and often take the old one away. Worth it for fridges; mind the staircases. |

Spotted a term this glossary should cover? That's a great [worksheet](worksheet.html) note; add it to your copy, and consider it homework from your own research, which is exactly how this manual hopes it gets used.
